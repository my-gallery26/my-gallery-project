About the Project

My Gallery is a university web development project. The website was created to display and organize photographs in a simple and user-friendly way.

The project contains different pages that allow visitors to explore photos, view albums and learn more about the website.

Project Goals

  • Create a simple photo gallery website.
  • Organize photos into different categories.
  • Create multiple connected HTML pages.
  • Practice HTML web development.
  • Create an easy navigation system.

Technologies

  • HTML5
  • CSS3
  • JavaScript
